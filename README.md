### 🔨 Currently Building

**[Zenith CMS](https://github.com/AmanTShekar/Zenith-CMS)** — Production-grade open-source headless CMS with multi-tenancy, per-tenant schema isolation, section-based page editing, HMAC-signed API requests, and a built-in AI proxy layer. TypeScript monorepo via Turborepo · Drizzle ORM · PostgreSQL. Targeting feature parity with Payload & Strapi.

**[zenith-terminal-buddy](https://github.com/AmanTShekar/zenith-terminal-buddy)** — VS Code extension that intercepts live terminal output and routes it through an LLM pipeline for real-time error analysis, fix suggestions, and dangerous-command interception. TypeScript · VS Code Extension API · esbuild.
