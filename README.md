### What I'm Building

**[Zenith CMS](https://github.com/AmanTShekar/Zenith-CMS)** — open-source multi-tenant headless CMS targeting production parity with Payload and Strapi. Per-tenant schema isolation, section-based page editing, HMAC-signed API requests, and a built-in AI proxy layer. TypeScript monorepo on Turborepo with Drizzle ORM + PostgreSQL.

**[zenith-terminal-buddy](https://github.com/AmanTShekar/zenith-terminal-buddy)** — VS Code extension that intercepts terminal output streams and runs them through an LLM to surface plain-English explanations, command suggestions, and dangerous-operation guards. esbuild-bundled, 99.8% TypeScript.
